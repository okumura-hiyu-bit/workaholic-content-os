# 実測記録

実素材でのPremiere検証と、目標値との差を記録する場所。

## 記録方針

**成功・失敗だけでなく、Premiere上で実際に必要だった操作数と修正箇所を必ず記録します。** 「読み込めた」だけでは、次に何を直せばよいかが分からないためです。

- 1エピソードごとに `YYYY-MM-DD_epNNN.md` を作成
- 最低3本そろった時点で `summary.md` に中央値と目標との差をまとめる
- 目標値は [12-premiere-capability-matrix.md](../12-premiere-capability-matrix.md) 12.6 / 12.8

## 記録テンプレート

以下をコピーして使います。

```markdown
# 実測記録 — epNNN

- 日付:
- 素材: 尺 __分 / 出演者 __名 / __fps / 解像度
- Premiereバージョン:
- 素材の置き場所: （内蔵SSD / 外付けSSD・マウント名 / パスに日本語や空白を含むか）
- 解析にかかった時間: __分（`contentos analyze` の実行時間）

## 検証項目（ご指定の10項目）

| # | 項目 | 結果 | 必要だった操作数 | 修正箇所・メモ |
|---|---|---|---|---|
| 1 | FCP7 XMLがPremiereで正常に読み込めること | ○/× | | |
| 2 | メディアが自動でリンクされること | ○/× | | |
| 3 | 各カメラの同期が合っていること | ○/× | | ずれていた場合は「どのカメラが何フレームずれたか」 |
| 4 | カメラ切り替えが想定どおり反映されていること | ○/× | | 直したカット数と、その理由 |
| 5 | 原音トラックが有効になっていること | ○/× | | |
| 6 | 補正音トラックがミュートされていること | ○/× | | |
| 7 | 字幕・話者名・強調テロップが読み込めること | ○/× | | |
| 8 | マーカーの位置とコメントが正しいこと | ○/× | | 欠落・位置ずれがあれば種類ごとに |
| 9 | ショートシーケンスの開始点・終了点が正しいこと | ○/× | | |
| 10 | 日本語や空白を含む外付けSSDのパスでも再リンクが発生しないこと | ○/× | | 実際に試したパス |

## 実測値（12.8の9項目）

| # | 項目 | 目標 | 実測 | 差 |
|---|---|---|---|---|
| 1 | 素材登録からFCP7 XML生成までの時間 | 25分以内 | | |
| 2 | PremiereへのXML読み込み時間 | 60秒以内 | | |
| 3 | メディア再リンクに必要な操作数 | 0 | | |
| 4 | 同期確認に必要な操作数 | 3以下 | | |
| 5 | 字幕適用に必要な操作数 | 6以下 | | |
| 6 | 縦型シーケンス調整に必要な操作数 | 2/本 | | |
| 7 | 編集者が初稿を確認する時間 | 記録のみ | | |
| 8 | XMLの読み込みエラー率 | 0% | | |
| 9 | 字幕・マーカーの欠落率 | 0% | | |

**欠落率の出し方**: 生成時に出力される `expected.json` の件数と、Premiere上の実数を突き合わせます。

## 精度の確認（解析結果 vs 編集者の判断）

| 項目 | 内容 |
|---|---|
| 同期オフセット | 推定値と、編集者が手で合わせ直した値の差（フレーム） |
| 話者判定の誤り | 誤った区間の数と、その状況（かぶりが強い / 声が小さい など） |
| 相槌の扱い | 相槌でカメラが切り替わってしまった箇所の数 |
| 笑いの検出 | 見逃し数 / 誤検出数（★暫定ヒューリスティックのため要調整） |
| ショート候補 | 採用した本数 / 提示された本数、および採用理由 |

## 所感（編集者の主観・自由記述）

- 実際に時間が減ったか
- 邪魔だった提案
- あると良かった情報

## 次に直すこと

- [ ]
```
