# 9. デザインシステム

## 9.1 方針

参照する3つのプロダクトから、それぞれ異なるものを取り入れる：

- **Apple**: 余白の取り方、タイポグラフィの階層、装飾を足さない姿勢。影・枠線は最小限にし、階層は「余白」と「わずかな明度差」で表現する。
- **Notion**: 情報の入れ物としての使いやすさ。動画詳細ページのタブ、アイデア一覧のギャラリー/テーブル切替など、「触っていて迷わない」構造。
- **Linear**: 操作感。キーボードショートカット（`C` で新規作成、`⌘K` でコマンドパレット）、即座に反映されるUI（楽観的更新）、カンバンのドラッグの軽さ。

## 9.2 カラー

### ベース（ニュートラル）
黒・白・グレーのみで構成し、色は情報の意味づけにのみ使う。ライト/ダーク両対応。

```
背景       #FFFFFF  /  ダーク: #0A0A0A
サーフェス  #FAFAFA  /  ダーク: #141414
ボーダー    #E5E5E5  /  ダーク: #262626
テキスト強  #0A0A0A  /  ダーク: #FAFAFA
テキスト中  #737373  /  ダーク: #A3A3A3
テキスト弱  #A3A3A3  /  ダーク: #737373
```

### アクセントカラー（要決定・3案）

WORKAHOLIC の正式なブランドカラーが不明のため、社名とサービス性格から3案を提案する。**いずれか1色のみ**を採用し、CTA・選択状態・グラフの主系列にだけ使う（多色使いはミニマルさを崩すため避ける）。

| 案 | HEX | 印象・根拠 |
|---|---|---|
| A. エレクトリックブルー | `#2563EB` | 最も無難で可読性が高い。「仕組み化する会社」という理性的・システム的な性格に合う。Linear寄り。 |
| B. バーミリオン（朱） | `#E5484D` | 映像制作会社としての熱量・アグレッシブさを表現。黒背景で最も映え、記憶に残る。ブランドの差別化を優先する場合。 |
| C. ライム／シトラス | `#84CC16` | 「WORKAHOLIC＝働き続ける熱量」を、重くならずエネルギッシュに表現。モノクロUIとのコントラストが強く、若い層向けSNS事業との相性が良い。 |

**推奨は B**。映像制作という表現業であることと、Phase2でクライアントに提示する画面であることを考えると、A は無難すぎて「制作会社らしさ」が出ない。ただし、既存のロゴ・名刺・Webサイトの配色がある場合はそちらを優先すべきなので、**現行のブランドガイドラインがあれば共有してほしい**。

### 意味色（固定）
```
成功  #16A34A     警告  #D97706     エラー  #DC2626     情報  #525252
```

ステータス（企画中/撮影待ち/編集中…）は色ではなく**グレースケール＋小さなドット**で表現し、アクセントカラーと競合させない。

## 9.3 タイポグラフィ

- 欧文: `Inter`（可変フォント）
- 和文: `Noto Sans JP` または OS標準（`Hiragino Sans`）
- スケール: 12 / 13 / 14 / 16 / 20 / 24 / 32px。本文は14px、テーブル内は13px。
- 行間は本文1.7、見出し1.3。日本語の可読性を優先し、欧文基準より広めに取る。

## 9.4 レイアウト原則

- 角丸: 6px（カード・ボタン）、8px（モーダル）で統一。
- 影: `0 1px 2px rgba(0,0,0,0.04)` 程度に留め、基本はボーダーで区切る。
- グリッド: 4pxベース。
- サイドバー幅240px固定、メインコンテンツは最大1440pxでセンタリング。
