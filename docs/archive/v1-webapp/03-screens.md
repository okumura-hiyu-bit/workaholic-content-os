# 3. 画面一覧

## 3.1 ログイン / オンボーディング
- メール＋パスワード（将来Google SSO）
- 初回ログイン時、ワークスペース作成 or 招待受諾フロー

## 3.2 ダッシュボード
一次要件のとおり、以下をカード形式で配置（Notion的な余白＋Linear的な密度のバランス）：
- 今週のタスク（担当者・期日つきリスト、完了チェック）
- 進行中の動画（ステータス別の件数バッジ＋直近更新3件）
- 投稿予定（直近7日間、プラットフォームアイコンつき）
- 最新KPI（登録者数・再生数・CTR等のサマリーカード、前週比）
- 登録者推移（折れ線グラフ、期間切替）
- 改善提案（AIが生成した直近の提案トップ3、クリックで詳細）

## 3.3 コンテンツ管理
表示切替: **カンバン / リスト / カレンダー**

カンバンの列（ステータス）:
`企画中 → 撮影待ち → 編集中 → 確認中 → 投稿予約 → 公開済 → アーカイブ`

- カードには サムネ案・タイトル・担当者・期日・優先度を表示
- ドラッグ&ドロップでステータス変更（Linear風の軽快な操作感）
- フィルタ: 担当者 / チャンネル / 期日 / 優先度
- 「＋新規動画」ボタン → アイデアからの変換 or ゼロから作成

## 3.4 動画詳細ページ
1本の動画のハブ画面。左にメタ情報（ステータス・担当者・期日）、右にタブ切替コンテンツ：

| タブ | 内容 |
|---|---|
| 企画 | コンセプト、ターゲット、ゴール、質問リスト（AI生成／編集可） |
| 構成・台本 | 台本本文、バージョン履歴、AI再生成ボタン |
| タイトル | AI生成のタイトル案複数、比較表示、採用フラグ |
| サムネ案 | AI生成のサムネ構成案（テキスト案＋参考ビジュアル指示）、採用フラグ |
| 概要欄 | YouTube概要欄テキスト、ハッシュタグ案 |
| ショート案 | 切り抜き候補（タイムコード・フック文言・対象プラットフォーム） |
| 編集指示 | 編集者向けの指示書（AI生成のたたき台＋ディレクターの修正） |
| 投稿履歴 | 各プラットフォームへの投稿状況・URL・投稿日時 |
| 分析結果 | 公開後のKPI推移、AIによる分析コメント |

「最終確認」ボタン＝ディレクターが担当する唯一のアクション。ここを押すとステータスが次工程に進む。

## 3.5 アイデア管理
- カード一覧（Pinterest風ではなくNotionのテーブル/ギャラリー切替を想定）
- 各アイデアに：出典（トレンド/競合/ニュース/YouTube/手動）、根拠URL、概要、想定スコア、ステータス（未着手/検討中/採用/却下）
- お気に入り登録（★）と、お気に入りのみでフィルタ
- 「動画化する」ボタン → コンテンツ管理に新規動画として登録（Ideaの情報を引き継ぐ）
- 競合チャンネル管理（登録した競合の最新投稿を横断表示）をこの画面のサブタブとして持たせる

## 3.6 投稿カレンダー
- 月表示カレンダー、プラットフォーム別に色分け
- 日をクリックで当日の投稿一覧、ステータス（下書き/予約済/公開済/失敗）
- TikTok/Instagramなど自動投稿できないプラットフォームは「予約済（要手動実行）」を明示し、当日リマインドを出す

## 3.7 KPIダッシュボード
- 表示単位切替：チャンネル単位 / 動画単位
- 指標: 登録者数、再生数、CTR、平均視聴維持率、コメント数、保存数、リーチ、インプレッション、問い合わせ数
- 期間フィルタ（週/月/カスタム）、比較（前期間比）
- 動画単位ビューでは、動画一覧を指標でソート（「伸びた動画トップ5」等）できるようにする

## 3.8 月次レポート
- 一覧（過去分のアーカイブ）＋当月の自動生成ドラフト
- 構成: 成果サマリー / 改善点 / 成功企画 / 失敗企画 / 来月の提案（要件どおり）
- ドラフトはAIが自動生成し、ディレクターが文面を編集してから「確定」
- 確定後はPDFエクスポート可能（クライアント提出を見据えたPhase2の要件を先取り）

## 3.9 設定
- ワークスペース情報（名称・ブランドカラー・ロゴ）
- チャンネル連携（YouTube/Instagram/TikTokの認証・接続状態）
- メンバー・権限管理
- AI設定：ブランドボイス（トーン、NGワード、ターゲット読者像）、生成のデフォルト言語・文字数レンジ
- 通知設定（タスク期日・投稿失敗などのアラート先）

## 3.10（Phase2）クライアント管理
- ワークスペース一覧・切替スイッチャー
- クライアントごとの契約プラン・利用範囲設定
- クライアント向け閲覧アカウントの発行
