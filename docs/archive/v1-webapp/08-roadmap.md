# 8. 開発ロードマップ

想定チームは小規模（フルスタック開発者1〜2名）を前提にした期間感。実際の着手可否に応じて調整する。

## Phase 0：基盤構築（1〜2週間）
- モノレポ初期化（pnpm + Turborepo）、Next.js / Prisma / Supabase セットアップ
- 認証・組織（Organization/Membership）モデルの実装、RLSポリシーの適用
- デザインシステムの土台（shadcn導入、カラートークン確定＝ブランドカラーのヒアリングが必要）
- 空のシェル画面（サイドバー、各ページのルーティング）

**完了条件**: ログイン→ワークスペース作成→空のダッシュボードが表示できる。

## Phase 1：MVP（コア運用フロー、3〜4週間）
- コンテンツ管理（カンバン/リスト/カレンダー、ステータス遷移）
- 動画詳細ページ（各タブ、手動入力ベース）
- アイデア管理（手動登録・お気に入り・動画化）
- KPI手動入力＋グラフ表示（自動連携はPhase3）
- ダッシュボード（実データでの集計表示）

**完了条件**: AIなしでも、企画〜投稿〜簡易分析までシステム上で完結して回せる状態。ここでディレクターの実運用に乗せ、フローの過不足を検証する。

## Phase 2：AI機能 第一弾（3〜4週間）
- `packages/ai` 基盤構築、`ai_generations` ログ設計の実装
- タイトル案・サムネ案・概要欄・ハッシュタグ・台本・質問リスト・編集指示書・切り抜き提案の生成
- アイデア提案（ニュース/YouTubeトレンドを起点にしたリサーチ→提案、週次バッチ）

**完了条件**: 動画詳細ページの各タブで「AI生成」ボタンを押すとドラフトが出力され、ディレクターが採用/修正できる。

## Phase 3：外部連携（3〜4週間）
- YouTube連携（OAuth、KPI自動取込、投稿）
- Instagram連携（KPI自動取込、投稿）
- TikTok連携（KPI取込。投稿は予約カレンダー＋手動実行から開始）
- 投稿カレンダーの本実装、リマインド通知

**完了条件**: KPIが自動更新され、ダッシュボードの数値が毎日最新化される。

## Phase 4：分析・レポート自動化（2週間）
- KPI分析AI（週次の異常値・傾向コメント）
- 改善提案AI（ダッシュボード表示）
- 月次レポート自動生成（ドラフト作成→編集→確定→PDFエクスポート）

**完了条件**: 月初に自動でレポートドラフトが生成され、ディレクターは確認・編集のみで完成できる。

## Phase 5：Phase2（クライアント展開）準備（継続）
- クライアントごとのAIブランドボイス設定（トーン・NGワード）
- クライアント向け閲覧ロール（Viewer）の権限精査
- クライアントオンボーディングフロー（ワークスペース作成の自助化）
- プラン・請求管理の要件定義（課金方式は別途ビジネス側で検討）

**完了条件**: 新規クライアントの受け入れが、コード変更なしにワークスペース作成のみで完結する。

## 進め方に関する補足
- Phase1完了時点で一度、実運用に乗せてフィードバックを取ることを強く推奨する（AI機能に投資する前に、ステータス設計やタブ構成が実際の制作フローと合っているかを検証するため）。
- `ai_generations` の履歴設計はPhase2の最初から入れておく。後から追加すると過去の生成物の効果検証ができなくなるため。
