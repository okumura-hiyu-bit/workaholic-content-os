# 5. 機能一覧

AI担当業務・人間担当業務のマッピング。「AI」列は完全自動ではなく、**AIがドラフトを生成し、人（ディレクター）が採用/修正するのが基本形**（品質担保のため、全自動公開は行わない）。

| 機能 | 担当 | 関連テーブル | 備考 |
|---|---|---|---|
| 市場リサーチ | AI | ai_generations, ideas | Web検索ツール併用 |
| 競合分析 | AI | competitors, ai_generations | 登録済み競合の最新投稿を定期取得→分析 |
| 企画立案・動画テーマ提案 | AI | ideas | 週次バッチ＋オンデマンド生成 |
| タイトル案作成 | AI | title_options | 動画詳細ページから複数案を再生成可 |
| サムネ案作成 | AI | thumbnail_concepts | テキスト構成案として生成（画像生成は将来検討） |
| 質問リスト作成 | AI | video_plans.questions_list | 撮影前のインタビュー設計を支援 |
| 台本作成 | AI | scripts | バージョン管理、再生成可 |
| 動画編集の指示書作成 | AI | edit_instructions | 台本＋構成からたたき台生成 |
| ショート動画の切り抜き提案 | AI | shorts_clips | タイムコード＋フック文言を提案 |
| 投稿文作成 | AI | posts.caption | プラットフォームごとの文体調整 |
| ハッシュタグ提案 | AI | descriptions.hashtags, posts.hashtags | |
| 投稿スケジュール管理 | システム（人が最終実行） | posts | 自動投稿はYouTubeのみ対応可、他は予約カレンダー＋リマインド |
| KPI分析 | AI | kpi_*_snapshots, ai_generations | 週次/月次で異常値・傾向をコメント生成 |
| 改善案の提案 | AI | ai_generations | ダッシュボードの「改善提案」カードに表示 |
| 月次レポート作成 | AI（ドラフト）→人（確定） | reports | 自動生成後、ディレクターが編集して確定 |
| 撮影 | 人（ディレクター） | videos.status = shooting_wait → editing | |
| ディレクション | 人（ディレクター） | 各タブでのAI出力の採用・修正 | |
| 最終確認 | 人（ディレクター） | videos.status 遷移の承認 | 唯一の必須人手ゲート |

## 5.1 システム基盤機能（AI/人の分類外）

- 認証・権限管理（org境界、role別アクセス制御）
- チャンネル連携（OAuth、トークン管理・更新）
- KPI自動取込ジョブ（日次）
- 通知（タスク期日、投稿失敗、AI提案の新着）
- 監査ログ（誰が何を変更したか）
- レポートのPDFエクスポート
- （Phase2）クライアントごとのブランドボイス設定切替
