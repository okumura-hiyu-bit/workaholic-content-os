# WORKAHOLIC Content OS — 設計ドキュメント

WORKAHOLIC株式会社の新規事業「ビデオポッドキャスト運用」を中心とした社内システムの設計一式。

## 目的の整理

- **Phase 1**: 自社チャンネル（ビデオポッドキャスト）を成長させながら、企画・編集・投稿・分析の「勝ちパターン」をシステムに蓄積する。ディレクターは撮影・ディレクション・最終確認に集中し、それ以外（リサーチ〜レポート作成）はシステム＋AIが担う。
- **Phase 2**: Phase 1 で確立した運用フローとシステムを、そのままクライアント企業へ提供する（マルチテナント展開）。

この前提のもと、**「動画1本」を中心にすべての情報が紐づく構造**、かつ**組織（ワークスペース）単位でデータが分離される構造**を、最初から採用する。あとから作り直すのが最もコストの高い部分（データモデルとマルチテナント境界）を土台に組み込んでおく。

## デザイン方針

- **トーン**: シンプル・ミニマル・洗練。Apple のUIの静けさ、Notion の使いやすさ、Linear の操作感（キーボード操作・即応性・カンバン）を参照する。
- **カラー**: 黒・白・グレーをベースとしたニュートラルなUI。アクセントカラー1色のみをWORKAHOLICのブランドカラーに合わせる（多色使いはしない）。実装フェーズでブランドカラーのHEX値を確定させる必要あり（要ヒアリング）。
- **情報密度**: Notion的な「詰め込みすぎない」余白と、Linear的な「一覧性の高いテーブル/カンバン」を両立させる。
